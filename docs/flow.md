# 流水线

从硬件到真机的完整链路。每步都有产物和通过判据，没过就不要往下走。

| # | 阶段 | 产物 | 通过判据 |
|---|---|---|---|
| 0 | 设计冻结 | 开源给什么/缺什么清单、BOM | 每个缺件都有归属（自做或买） |
| 1 | 硬件到位 | 供电、通信、单关节可控 | 15 个关节逐个动，急停有效 |
| 2 | 数字描述 | base + overlay → resolved 描述 | 结构检查过（解析/树/惯性/mesh/限位） |
| 3 | 语义检查 | 关节序/零位/方向/单位/限幅对照表 | 与固件、驱动器协议逐项一致 |
| 4 | 对齐 | 姿态回读误差表 | 关节角、末端位置误差在阈值内 |
| 5 | 标定 | overlay 增量 | 回填后误差下降且可复现 |
| 6 | 辨识 | 动力学参数 + 延迟/摩擦表 | 仿真能复现真机响应曲线 |
| 7 | 站立 baseline | sim 与真机各一份 | 真机站得住 |
| 8 | 重定向 | 参考动作 + 指标报告 | 脚滑/穿透/接触相位/节奏过线 |
| 9 | 训练 | 策略 ONNX + manifest | 仿真连续走 60 s |
| 10 | sim2sim | 环境差异报告 | 逐项对齐 + 轨迹偏差在阈值内 |
| 11 | sim2real | 分级放行记录 | 吊架 → 限幅 → 真机 10 分钟 |
| 12 | 回归 | SOP 更新、事故单 | 每次改动有记录 |

## 几条硬规矩

- **标定 ≠ 辨识**：标定在 4 之后、辨识之前；辨识需要能施激励轨迹，依赖安全层。
- **描述只有一个 canonical**：base 只读，标定只写 overlay，USD/MJCF 都是导出产物。
- **对齐必须有量化判据**：没有误差表的「对齐」不算完成。
- **不必串行**：没有硬件时，2、3、8、9、10 可以先做；硬件到了只补 4、5、6、7。
