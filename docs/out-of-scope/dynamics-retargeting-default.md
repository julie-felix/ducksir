# 不把动力学重定向当默认路径

- 日期：2026-11-07
- 状态：否

## 提了什么

用 KDMR 式的多接触全身轨迹优化（arXiv 2603.09956）作为默认重定向方案：约束刚体动力学与接触互补，产出物理可行的参考动作。

## 为什么否

- 每个新动作都要重新解一次优化，批量化成本高。
- 论文自述代码「upon publication」，目前拿不到。
- 鸭脚接触面大、腿短，人形的 heel-toe 接触事件检测不适用，接触定义要重做，收益不确定。

## 什么条件下可以重新考虑

学习式重定向产出的参考在物理可行性上系统性不过闸门（脚滑/穿透持续超标），或开始做接触丰富的动作（跳、翻、单脚支撑切换）。
