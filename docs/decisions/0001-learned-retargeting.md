# ADR-0001 训练与重定向：B+A 双层学习重定向

- 状态：已定
- 日期：2026-11-07
- 决策人：庆喆
- 影响范围：`training/retarget`、`training/track`、`contract`（reference motion 格式）

## 背景

项目要拿到两件能力：**稳定行走**和**可编排的舞蹈**。舞蹈的本质是"让机器人跟一段参考动作"，所以整条链上真正决定上限的不是 RL 算法，而是**参考动作的质量**。

重定向（把人类/视频/动捕动作变成机器人关节轨迹）有三条路：

| 方案 | 做法 | 问题 |
|---|---|---|
| A 监督学映射 | 用 IK/轨迹优化产一批高质量目标，训网络快速出参考 | 天花板＝数据质量，本质在模仿 IK |
| B RL 学 retargeter | 策略输出目标动作/残差，奖励＝相似度＋物理可行，跟踪器当评判 | 双层优化，冷启动差、不稳定、成本高 |
| C 端到端 | 只给部分观测，策略直接跟任意运动子集（masked mimicry 类） | 重定向消失，出问题分不清是参考错还是策略没学会 |

另有纯优化路线（如 KDMR，多接触全身轨迹优化），它能出物理可行的参考，但不"学"，且对每种新动作都要重解一遍。

## 决策

**采 B+A 组合，C 不采用（保留为对照）。**

1. **A 当数据引擎**：先用 IK 类重定向（GMR 思路）批量产出参考轨迹，把跟踪器（mjlab PPO）训起来。目标不是好，是"有"。
2. **B 当优化器**：跟踪器可用之后，训一个 retargeter 网络，输入源动作、输出机器人参考，奖励 = 形态相似度 + 物理可行性（脚滑/穿透/关节限位）+ 跟踪器实际跟踪误差。也就是让重定向去适配"这个跟踪器学得会什么"。
3. **优化路线（KDMR 类）保留为 L1 的可替换实现**：当 B 产出的参考在物理上明显不可行时，用它做参照与对照，而不是默认路径。

## 为什么

- **纯 B 冷启动不可行**：没有可用跟踪器时，retargeter 的奖励是空的，双层优化会退化成随机搜索。
- **纯 A 的天花板太低**：A 只能逼近 IK 的解，而 IK 解在 15 DOF 的小鸭子上会系统性地产生脚滑和穿地，跟踪器学得越认真越像在学错误动作。
- **B+A 的分工让每一步可验收**：A 阶段用可解释指标验收（脚滑/穿透/节奏），B 阶段用跟踪误差和真机表现验收。中间任何一步崩了都能定位。
- **重定向值得单独学**：重定向质量直接决定跟踪上限（见 GMR 那篇 *Retargeting Matters*）。

## 硬性约束（防"讨好跟踪器但不像跳舞"）

B 的奖励必须有**可解释的相似度项**，不能只看跟踪 reward，否则网络会学出跟踪器爱吃、但人看着不对的动作。每条参考轨迹必须同时过：

- 脚部落点与支撑相时序（footfall / contact phase）
- 质心高度与躯干朝向
- 动作节奏（节拍对齐，舞蹈尤其重要）
- 关节限位与速度上限
- 脚滑（m/步）、地面穿透（mm）

任一项超阈值即标黄或标红，进 `training/retarget/reports`，不静默通过。

## 管线

```
源动作（视频/动捕/手工）
   │
   ▼
[L0 重定向 · 可替换实现]  IK/GMR  ──或──  KDMR 类轨迹优化
   │  产出：参考轨迹 + 接触相位 + provenance
   ▼
[跟踪器 mjlab PPO] ──误差反馈──▶ [B: retargeter 网络]
   │                                  │
   │◀──────── 新参考 ────────────────┘
   ▼
策略（ONNX + manifest）──▶ sim2real
```

## 后果

- 工作量集中在两处：**源动作的获取**（版权与形态适配）和**双层训练的成本控制**。
- `contract` 里 reference motion 必须成为一等公民：关节轨迹 + base 轨迹 + 接触相位 + 时间轴 + provenance。少了任何一项，重定向结果就没法被下游校验。
- 参考动作来源未定：LAFAN1 是 CC BY-NC-ND（禁商用禁演绎），SMPL-X 非商用。**对外产品必须自采**；练手阶段可以先用公开数据，但不进对外产物。
- 本机无 GPU，L1/L2 都在云上跑，单机 1–8 卡、一次几 GPU·小时，不需要集群。
